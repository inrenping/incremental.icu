# incremental.icu 介绍

**incremental.icu** 是一款专为运动爱好者打造的跨平台数据同步工具。它能够连接佳明（Garmin）与高驰（Coros）平台，通过调用官方提供的 API 同步数据，协助用户高效管理运动记录，特别适合同时使用多设备记录运动状态的用户。

创建这个工具的初衷，是为了解决佳明海内外版本数据不同步导致 Strava 和微信运动等数据国内平台只能二选一的问题。后来使用了高驰训练平台感觉不错，于是增加了高驰的平台支持。

## 你可以用 incremental.icu 做什么

登录后进入仪表盘，顶部有四个标签页：**跑量 / 同步 / 睡眠 / 心率**。

### 跑量

- 查看**年度 / 月度**跑量：次数、距离、时长，以及目标完成度和时间进度条（点击卡片直接进入运动日历）；
- **近 30 天跑量柱状图**（统计主数据源的跑步类运动）；
- **主数据源最近记录**：最近 5 条运动，点击可跳转查看/操作。

> 「主数据源」是你在已连接平台中指定的那个主要账号，跑量统计、近 30 天图表和最近记录都以它为准。

### 同步

- **一键同步**：设定源账号与目标账号，拉取两端各最新 10 条做差量同步，执行完直接显示汇总结果；
- **手动同步**：在「详细数据查询」里增量/全量拉取记录，再对单条记录下载 FIT 或推送到指定平台；
- **定时同步**：在「定时任务」里配置自动生成同步，每用户最多 10 个任务，每个任务一条「源 → 目标」同步配置，每天最多执行 3 次。

### 睡眠

- **月度报告**：当月每天的睡眠时长以时钟环形图呈现，一览整月作息；
- **日历月历**：按日查看睡眠时长，点开可看单日的深睡 / 浅睡 / REM / 清醒分段详情；
- 数据来自**佳明平台**，可手动触发月度同步拉取。

### 心率

- 每日心率汇总：**最高、最低、静息心率**，以及**近 7 日静息心率均值**；
- 当日心率曲线，并叠加昨日曲线做对比；
- 数据来自**佳明平台**，也可直接访问 `/heart` 独立页面查看。

### 其他

- **运动日历**：按周查看运动分布，支持按运动类型区分；
- **运动文件**：查看已缓存的活动文件；
- **GPT Code**：生成一次性授权码，把数据通过 MCP 接入 ChatGPT 等客户端；
- **同步历史 / 日志**：查看每次同步与操作记录。

## 支持的平台

| 平台 | 支持状态 | 文件格式 |
| :--- | :---: | :--- |
| 佳明 (Garmin) 国内版 | ✅ 已支持 | **FIT** |
| 佳明 (Garmin) 国际版 | ✅ 已支持 | **FIT** |
| 高驰 (Coros) | ✅ 已支持 | **FIT** |

心率与睡眠数据目前仅支持佳明平台。
